### Pitfalls

1. **The altar loader's coordinates.** ch4 lines 859–869 measure the tiers in world coordinates, then subtract `homeAltar.position`, which is local. That only works when the parent sits at the origin; in the pocket it is off by 300 m. `Box3.setFromObject` also never refreshes ancestors. Fix: measure the tiers while the model is still unparented, after setting its position (then they are already in `homeAltar`'s frame), and use `fx = lower.max.x - 0.14` with no subtraction.
2. **A directional light's target defaults to the world origin.** Placed inside the pocket, `duskFill` would point from (-302, 4, -10) toward the origin. Give it a target object added to `F`. The global key and fill are direction-only, so they are fine.
3. **No shadow map reaches 300 m out.** The moon's shadow covers ±20 m around the origin, and the ceiling light here casts none. So the key light passes through the walls: keep it low. The ceiling light will also lightly fill the kitchen stub; that matches what ch4 looked like on a phone.
4. **The light count changes, and shaders key on it.** The new lights must sit inside `F` and be dark when the loading screen warms the shaders, so the warm-up (main.js:10602–10706) treats them as one group, and as a sibling pair with `T`'s `tlight`. e3c2 has no entry in `src/lightseeds.json`. Check once that no shader is built during shot 3 by comparing `renderer.info.programs.length` before and after.
5. **The sky dome is a fixed 150 m sphere at the origin** (main.js:704–712). From 300 m out it is beyond the far plane, so the window shows the flat background colour 0x2a2547. For desktop accuracy, add a backdrop in `F`: a back-face sphere of radius about 100, ch4's stops painted the way `paintSky` does, fog off, depth test and depth write off, render order -999. On a phone the window is out of frame.
6. **`kit.daylight` must be a step, not a per-frame track.** A track that has started runs every frame after it, clamped to its end value, so it would keep reapplying the flat's light after 35.6. Steps fire once, in the order they are written.
7. **Fog.** Lit materials keep fog on. At 2 m and density 0.010 that matches ch4; the swap supplies ch4's fog colour.
8. **The far plane is 160 m.** The grass reaches z -126 from the pocket. No other pocket or the hall can see it: the nearest is about 190 m away.
9. **This is a re-staging Chad asked for**, unlike the v14.10 case, where an addition to a shot became a re-staging he had not asked for. Keep the beat timings exactly as they are.

- Two overlay planes, also 0.6 m, so no edge can ever show:

**Needle**

**Ink: three layers**
- **Live letters:** 3 quads, one per letter i = 0..2.
  - `PlaneGeometry(1.2*MACRO.size, 1.2*MACRO.size)`, i.e. a 12-unit box with a 1-unit margin, 14.0 mm square.
  - At (0, `MACRO.y` − i·step, 0.0004), with `rotation.z = −0.07*j(i)` for the khomInk hand-wobble.
  - Each has its own canvas: 512² on desktop, 384² when `LOW`. `tex.generateMipmaps = false; tex.minFilter = THREE.LinearFilter`, because these are about 1:1 or magnified on every device.
  - Canvas transform: `x.setTransform(S/12, 0, 0, S/12, S/12, S/12)`, so the glyph's (5,5) is the quad centre.
  - Unit → pocket-local: `local = R(rot) · ((u−5)·k, −(v−5)·k) + quadPos`, with `k = size/10`.
- **Done letters:** one merged mesh, or about 35 small meshes sharing one texture.
  - An atlas of 6 glyph variants drawn complete in the same style: 3×2 cells of 512 (`LOW`: 384). These are uploaded once at build and warmed under the curtain.
  - Live column (x = 0): rows r = +1..+3 above the first live letter.
  - The four finished columns at x = −gap·1..4: rows r = +3..−4.
  - Below the live letters is bare skin: the work is in progress.
  - Optional: e3c1's Chat Petch net (5042–5050) between the finished columns. Only a desktop frame sees it.
- **Ink style:** smaller than v19.2's, so that loop heads stay open loops at macro scale.
  - Halo 2.0 mm at rgba(178,52,40,0.12), then 1.2 mm at 0.18.
  - Ink 0.5 mm at rgba(10,10,18,0.95).
  - On live letters only, a 0.12 mm wet highlight at rgba(255,240,230,0.15), offset −0.06 mm.
  - Divide millimetres by 1.17 to get units.
  - Do not use `ctx.filter` blur: Safari does not support it.

### 4b. Stroke-by-stroke drawing (copy into e3c2 beside `KHOM_INK`)
```js
function flattenKhom(d) {                       // → [{pts, cum, len}] in the 10x10 box, y down
  const tk = d.match(/[a-zA-Z]|-?(?:\d+\.\d*|\.\d+|\d+)/g), out = [];
  let cur = null, x = 0, y = 0, i = 0, cmd = '';
  const n = () => +tk[i++], to = (px, py) => { cur.push([px, py]); x = px; y = py; };
  while (i < tk.length) {
    if (/[a-zA-Z]/.test(tk[i])) cmd = tk[i++];
    if (cmd === 'M' || cmd === 'm') { const px = n(), py = n(); if (cmd === 'm') { x += px; y += py; } else { x = px; y = py; }
      cur = [[x, y]]; out.push(cur); cmd = cmd === 'm' ? 'l' : 'L'; }
    else if (cmd === 'L') to(n(), n());
    else if (cmd === 'l') { const dx = n(), dy = n(); to(x + dx, y + dy); }
    else if (cmd === 'V') to(x, n());
    else if (cmd === 'H') to(n(), y);
    else if (cmd === 'Q') { const qx = n(), qy = n(), ex = n(), ey = n(), x0 = x, y0 = y;
      for (let s = 1; s <= 14; s++) { const u = s / 14, v = 1 - u; to(v*v*x0 + 2*v*u*qx + u*u*ex, v*v*y0 + 2*v*u*qy + u*u*ey); } }
    else if (cmd === 'a') { n(); n(); n(); n(); const sw = n(), dx = n(), dy = n();   // every arc in KHOM_INK is a half circle
      const cx = x + dx / 2, cy = y + dy / 2, r = Math.hypot(dx, dy) / 2, a0 = Math.atan2(y - cy, x - cx);
      for (let s = 1; s <= 16; s++) { const a = a0 + (sw ? 1 : -1) * Math.PI * s / 16; to(cx + r * Math.cos(a), cy + r * Math.sin(a)); } }
    else throw new Error('flattenKhom: ' + cmd);
  }
  return out.filter(p => p.length > 1).map(pts => { const cum = [0];
    for (let k = 1; k < pts.length; k++) cum.push(cum[k - 1] + Math.hypot(pts[k][0] - pts[k - 1][0], pts[k][1] - pts[k - 1][1]));
    return { pts, cum, len: cum[cum.length - 1] }; });
}
```

- The lone `M2.3 7.6` before each `m` is a one-point subpath; the filter drops it.
- Draw the halo pass, then the ink pass, by calling `strokeTo` with a different style each time.

**Pokes.** For each live letter, split its strokes into `MACRO.per` = 6 pieces:
- Count per stroke = max(1, round(6·len/total)), adjusted by largest remainder so the counts sum to 6. Every glyph has at most 3 subpaths, or 4 with an e3c1 mark; skip `KHOM_MARK[1]`, which is a dot.
- Each stroke is cut into equal-length pieces `{a, b}` in the letter's cumulative length coordinate. A piece never crosses a pen-up.
- Tap j = 6·i + p gives `tp = YANT_TAPS[j]`. Letters change between taps 6→7 (3.3→3.75) and 12→13 (5.8→6.2), each a gap of about 0.4 s.
- Worked example, glyph 0: head ring about 5.6 units, stem and arch about 13, second arch about 10. That gives 1 + 3 + 2 pokes.

### 4c. Driving it from the film clock: a pure function, seek-safe
```js
function yantAt(ct) {
  // INK — want = revealed length quantised to quarter-pokes; redraw only when it changes
  for (const Lt of live) {
    let want = 0;
    for (const pc of Lt.pieces) { const e = Math.min(1, Math.max(0, (ct - pc.tp) / MACRO.drag)); want += (pc.b - pc.a) * Math.floor(e * 4) / 4; }
    want = Math.round(want * 1e4) / 1e4;
    if (want !== Lt.drawn) { Lt.ctx.clearRect(...); drawLetter(Lt, want); Lt.drawn = want; Lt.tex.needsUpdate = true; }
  }
  // NEEDLE — on the stroke while dragging; lifted, travelling to the NEXT piece's start, between taps
  const j = pcs.findIndex(p => ct < p.tp + MACRO.drag), cur = j < 0 ? null : pcs[j], prev = j < 0 ? pcs[pcs.length - 1] : pcs[j - 1];
  let P, lift;
  if (cur && ct >= cur.tp) { P = worldAt(cur.Lt, cur.a + (cur.b - cur.a) * smooth((ct - cur.tp) / MACRO.drag)); lift = 0; }
  else { const A = prev && worldAt(prev.Lt, prev.b), B = cur && worldAt(cur.Lt, cur.a), t0 = prev ? prev.tp + MACRO.drag : 0;
    P = A && B ? A.lerp(B, smooth((ct - t0) / Math.max(1e-3, cur.tp - MACRO.inT - t0))) : (B || A);
    lift = MACRO.lift * Math.min(1, prev ? (ct - t0) / MACRO.outT : 1, cur ? (cur.tp - ct) / MACRO.inT : 3); }
  rod.position.copy(P).addScaledVector(away, 0.0003 + lift);
  /* dimple opacity = 0.35*(1 - lift/MACRO.lift); shadow quad from P offset by lift */
}
```
- `worldAt` uses the quad transform from 4a. It returns a fresh vector or a scratch one; `lerp` mutates `A`, so clone it first.
- The tip is unquantised, so it leads its ink by less than a quarter of a piece for under 0.1 s. That reads as the needle drawing.
- **Call it from the intro as a track: `tr(0.0, 10.0, (k, t) => F.yantAt(t), rawK)`**, and delete the rod block in `tick` (2581–2591) so only one thing writes the needle. Calling it from `tick(ct)` would also be same-frame, but the track sits with the camera tracks.

Why this is seek-safe:
- The output is a pure function of `ct`, with no accumulation. The only state is the per-letter `drawn` cache, and that is just a "same as last time" check.
- `cineSeek` re-applies the track at every `t`, so a backward seek (`__enc.cine.seek`), a replay and a skip (`cineSeek(dur)`) all redraw exactly.
- Never draw from a `step`: steps fire once and cannot be undone by a backward seek. Never draw from the `sfx` cues: stings are not callbacks.
- After t = 10 the track keeps running with `t` > 10, but the cache stops any redraw.

### 4e. Redraw budget
- Only the current letter's canvas changes. There are at most 4 uploads per tap, so 72 or fewer over 7.3 s (about 10 a second).
- Each upload is 512² RGBA = 1.0 MB, or 0.59 MB at 384² on `LOW`. three uses `texSubImage2D` when the size is unchanged, and mipmap generation is off, so each upload costs well under a couple of milliseconds on a phone.
- The canvas draw itself is 2–4 short polylines times 4 passes: microseconds.
- One-time costs, all warmed under the curtain: atlas about 6 MB (`LOW` about 3.4 MB), skin tile 1 MB, overlays 256².
- GPU total about 12 MB, against roughly 6 MB for v19.2's ink sheet plus the skin.
