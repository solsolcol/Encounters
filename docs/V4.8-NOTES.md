## The engine seam

`CHCTX` now carries `cloneSkinned` (SkeletonUtils' clone), so a chapter
can clone a rigged scene without importing anything. That is the only
engine change the three models needed.

## Traps for the next build

- three.js `bindMode 'attached'` cancels a skinned mesh's node transform
  every frame. Sharing a skeleton across placed clones REQUIRES
  'detached' + identity binds (and this file's glTF rebind is identity;
  a file with a real bindMatrix would need it folded in).
- gltf-transform `normals()` = FLAT normals = unindexed output. For a
  smooth scan, ship no normals and grow them in the loader.
- eleven_v3 refuses a tags-only prompt (all takes fail, every run) —
  give breath lines voiceable non-words.
- The sfx model (eleven_text_to_sound_v2) returns takes of varying
  length; pick by SPECTROGRAM (structure: click → swing → settle), then
  peak-match the winner to the file it replaces.
