## 9 · Rules of this build that are easy to forget

- The Meshy key lives only at `/root/.config/meshy/key`: never printed, committed or written anywhere else. Upload
  links and signed content links are credentials: on the command line only, never in a file.
- The photographs are never committed and no face or name from them goes to a picture service. Nobody in them is
  copied.
- Downloaded files are untrusted: Python that reads them runs with `-I`, in a directory of their own.
- `src/chapters/e4/e4c2.js` is generated (masters/v25.0/assemble.py): never edited by hand. This chapter's file may be
  assembled the same way from parts if it grows large; say so here the day that is decided.
- Never delete code by line range; read the full diff before every commit.
- No reviewer agents (his word of 7 Nov): the picture checks are mine, and said honestly.
- Reports to Chad: one phone screen. The detail lives here and in the plan.
- Room on the machine: nothing is compressed to make room; only approved leftovers are cleared; a new intermediate of
  this build is cleared once its recipe is written and its result is kept.
