## The effect — `evGuard`, and exactly what it covers

`ITEM_DEFS[id].evGuard = f` means: while that item is WORN, every stat
DECREASE a minigame causes is multiplied by `(1 − f)`. For this amulet f = 0.5.
`evCut(delta)` is the one function; every minigame charge goes through it:

| charge | where | example, halved |
|---|---|---|
| a badly graded press, an early press, a slot left unanswered, a missed beat (flat `missCost` included) | `evScorePress` | heartbeat miss 5 → 2.5 sanity; sequence BROKEN −4 → −2 awareness |
| a wrong drop in the match game | `evMatchDrop` (`wrongCost`) | −4 → −2 awareness |
| the event's closing payout when it is a LOSS (a floored match, a failed timed/hold/mash/stabilise with a negative `lo`) | `evResolve` | −6 → −3; `r.delta` is what was applied, `r.full` what it would have been |
| a chapter's OWN price for failing a minigame | `kit.award(stat, d, { minigame: true })`, `kit.conduct({ …, minigame: true })` | e2c1's failed standby bed: −4 → −2 sanity on the card |

All three stats (sanity, awareness, wisdom). Gains are never touched. Not
minigames, so NOT cut: the ghost, the drain, the hurt bleed, a choice's
delta, the decision clock running out, the fall-in lateness. The graded
ladder nets its end payout against the FULL price paid, then cuts only what
is still owed, so the guard is applied exactly once. Worn with nothing else,
the halved amount is exact (2.5); the bars round what they show.

**Rule for every future minigame**: a new event kind charges through
`evScorePress`/`kitAward` inside the engine and is covered automatically; a
chapter that adds its own penalty for a failed event must mark it
`{ minigame: true }`, or the amulet will not see it.
